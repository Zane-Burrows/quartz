My best friend's organic chemistry professor introduced us to the idea of Type 1 vs Type II fun.

Type I vs Type II fun
- Type I fun is hedonic. It is related to immediate gratification and rewards.
- Type II fun is eudaemonic. It is related to a set of accomplishment and personal growth.

A conversation with D on short-term happiness:
- "You need to have the short-term happiness because sometimes you need that little spark to get you doing something"
- This concept is related to [[Behavioral activation]] in cognitive behavioral therapy, in which engaging in positive activities can improve mood
